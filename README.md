# ML 慢慢學 🐌

一步一步，用白話搞懂機器學習。

這是 YouTube 頻道 **[ML 慢慢學](https://www.youtube.com/@ml-step-by-step)** 的程式碼與 notebook。每支影片都有一個對應的 notebook，影片裡的每一張圖都由它算出，可以直接在瀏覽器中執行，不需要安裝任何軟體。

Code and notebooks for the YouTube channel **ML 慢慢學** — machine learning explained step by step in Traditional Chinese. Every chart in each video is computed by its notebook.

## ▶️ 如何執行 How to run

1. 在表格中點選 **Open in Colab**，用 Google Colab 免費在瀏覽器執行
2. 選單「執行階段 → 全部執行」（Runtime → Run all）
3. 第一次執行會自動安裝中文字型，約 30 秒

影片中的資料皆為**模擬資料**，非實際量測。All data in the videos are simulated.
